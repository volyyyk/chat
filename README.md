# MedChat — репозиторий телемедицинской платформы

Репозиторий содержит две версии проекта:

| Папка | Что это | Статус |
|---|---|---|
| `medchat/` | MedChat v1 — первая версия (legacy) | Заморожена, не развивается |
| `medchat-v2/` | MedChat v2 — актуальная версия | Активная разработка |

---

## 📊 Шкала реализации MedChat v2

**Общая готовность: ~85 %**

| Направление | Готовность | Что сделано | Что осталось |
|---|---|---|---|
| Сервер (API, чаты, платежи, приёмы, рецепты) | 88 % | REST + Socket.IO, платные сообщения с тестовым балансом, сплит 80/20, файлы в MinIO, RBAC, ownership-проверки; user-API полностью оживлён (профиль/пароль/аватар/админ-список), печатная форма рецептов со специальностями, композитный индекс пагинации сообщений | Прод-режим (реальные шлюзы отключены по требованию), подписи вебхуков |
| Безопасность | 88 % | bcrypt-12, JWT HS256 с пиннингом, refresh-ротация, Joi stripUnknown, rate-limit, MIME-фильтр, security-аудит с фиксами + 4 набора security-тестов; privateKey вырезан из req.user, fail-fast на слабый JWT_SECRET, смена email/username требует currentPassword | captcha на public endpoints, подписи вебхуков |
| Мобильный клиент (Expo) | 85 % | Все роли, чат server-first с socket+REST, голосовые, файлы, приёмы, рецепты, платежи; починен краш локальной БД во всех экранах (экспорт database/initDatabase), удалены мёртвый ChatProvider и сломанный encryptionService, старт без искусственной задержки | UI-полировка, локализация, виртуализация длинных чатов |
| Web-клиент | 70 % | Страницы клиники/админа, запуск через лаунчер на :3002 | Доп. экраны, полировка |
| Тесты | 78 % | unit + integration + security (без БД), e2e smoke 50 проверок по всем ролям с диагностикой stdout при падении, seed-аккаунты | Расширить покрытие (файлы, приёмы) |
| CI/CD | 85 % | GitHub Actions: jest + e2e smoke с Postgres/Redis; зелёный стабильно (runs #30, #31), логи падений автоматом публикуются в ci-logs/ | Артефакты, деплой |
| Инфраструктура | 82 % | docker-compose (pg/redis/minio), лаунчер «по кнопке» (проверен, папка удаляемая) | nginx/TLS, бэкапы по расписанию |
| Документация | 88 % | API, ARCHITECTURE, DEPLOYMENT, GETTING_STARTED, SECURITY_AUDIT, LEGAL, readme_for_AI (актуализирован: решённые заплатки отмечены) | Обновлять при изменениях |

## 🚀 Быстрый старт

```bash
# Запуск «по кнопке» (клиника / врач / пациент / всё сразу):
cd medchat-v2/launcher
node launch.js          # меню: 1-clinic, 2-doctor, 3-patient, 4-all

# Или вручную:
cd medchat-v2/server
cp .env.example .env    # при наличии
npm install
npm run seed:test       # тестовые данные
npm run dev             # сервер на :3000
```

Тестовые аккаунты (пароль у всех `Test1234!`):
- `admin@medchat.test` — clinic_admin
- `doctor@medchat.test` — врач
- `patient1@medchat.test` (баланс 200 ₽), `patient2@medchat.test` (баланс 1000 ₽) — пациенты

Тесты:
```bash
cd medchat-v2/server
npm test                # unit + integration + security (БД мокается)
npm run test:smoke     # e2e по всем ролям (нужны Postgres/Redis)
```

## 🔒 Безопасность

Проведён security-аудит с попытками взлома: саморегистрация администраторов запрещена,
цены фиксируются только сервером, JWT с пиннингом алгоритма, чужие транзакции/чаты
недоступны (IDOR-тесты). privateKey больше не покидает сервер, слабый JWT_SECRET
блокирует старт. Реальные платёжные шлюзы отключены (только тестовый баланс).
Подробности: `medchat-v2/docs/SECURITY_AUDIT.md`.
