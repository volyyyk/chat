# Первый тест MedChat — пошагово для Windows

Цель: бесплатно запустить тестовый контур на своём компьютере и подключить Android-телефон. Это **только демонстрация на вымышленных аккаунтах**. Не загружайте реальные ФИО, телефоны, документы, анализы или медицинскую переписку.

## Вариант A — посмотреть интерфейс за 5 минут (без компьютера-сервера)

Это самый простой вариант, но он использует эмулятор API, а не настоящее приложение целиком.

1. Откройте [тестовый релиз](https://github.com/volyyyk/chat/releases/tag/v0.0.1-alpha).
2. Скачайте два файла:
   - `MedChat-ServerMock-Android-debug.apk` — приложение-сервер-заглушка.
   - `MedChat-Android-debug-unsigned.apk` — Android-клиент.
3. На Android откройте скачанные APK из приложения «Файлы». Если Android спросит разрешение, разрешите установку приложений для браузера/«Файлов» и подтвердите установку. Это тестовые unsigned/debug APK, не версия из Play Store.
4. Сначала откройте **MedChat: тестовый сервер** и нажмите **Запустить**.
5. Затем откройте **MedChat**. На экране подключения укажите `http://127.0.0.1:8080`, если обе программы установлены на одном телефоне.
6. Нажмите **Проверить/Подключиться**, затем войдите с любым email и любым паролем.
7. Откройте один из двух демо-чатов и отправьте сообщение.

Ограничения этого варианта: сервер-заглушка хранит данные только в памяти, после перезапуска они исчезают; нет настоящей БД, E2E, файлов, платежей и Socket.IO. Никаких настоящих пользователей сюда не вводить.

## Вариант B — настоящий backend локально на ПК (бесплатно)

Нужно: Windows 10/11, Docker Desktop с включённым WSL2, Git и Android-телефон. Домен и VPS не нужны.

### 1. Установить программы

- Docker Desktop: https://www.docker.com/products/docker-desktop/
- Git for Windows: https://git-scm.com/download/win

После установки Docker Desktop откройте его и дождитесь статуса **Engine running**.

### 2. Скачать проект

1. Откройте https://github.com/volyyyk/chat
2. Нажмите зелёную кнопку **Code** → **Download ZIP**.
3. Распакуйте архив, например, в `C:\MedChat\chat`.
4. Откройте папку `medchat-v2\docker` внутри распакованного проекта.
5. В адресной строке Проводника напишите `powershell` и нажмите Enter.

### 3. Запустить сервер и базы

В открывшемся PowerShell вставьте по очереди:

```powershell
docker compose up -d --build
docker compose ps
```

Первый запуск скачает образы и соберёт сервер — это может занять несколько минут. В `docker compose ps` должны быть запущены postgres, redis, minio и server.

Создайте демонстрационные аккаунты:

```powershell
docker compose exec server npm run seed:test
```

Проверьте сервер:

```powershell
Invoke-RestMethod http://localhost:3000/health
```

Ожидаемый ответ содержит `status : ok`.

### 4. Открыть web-клиент на компьютере (по желанию)

В том же PowerShell:

```powershell
docker compose --profile web up -d --build
```

Откройте в браузере http://localhost:3002.

Для входа используйте тестовые аккаунты (пароль общий `Test1234!`):
- врач: `doctor@medchat.test`
- администратор клиники: `admin@medchat.test`
- пациент 1: `patient1@medchat.test`
- пациент 2: `patient2@medchat.test`

### 5. Подключить Android к backend на компьютере

1. Убедитесь, что телефон и ПК подключены к одной Wi-Fi сети.
2. На ПК откройте PowerShell и выполните `ipconfig`.
3. Найдите у активного Wi-Fi адаптера строку **IPv4 Address**, например `192.168.1.25`.
4. На телефоне откройте MedChat → экран подключения.
5. Введите адрес `http://192.168.1.25:3000`, заменив IP на свой.
6. Если Windows Firewall спросит разрешение, разрешите доступ для частной сети. Не открывайте порт 3000 в публичных сетях и не настраивайте проброс портов на роутере.
7. Войдите тестовым аккаунтом. Для проверки E2E нужен второй клиент/устройство и регистрация ключей обеих сторон.

Если телефон не подключается: проверьте, что Wi-Fi один и тот же, сервер отвечает на ПК по `http://localhost:3000/health`, а VPN временно отключён. Не отключайте Firewall целиком.

### 6. Остановить и удалить тестовые данные

Остановить контейнеры, сохранив базу:

```powershell
docker compose --profile web down
```

Полностью удалить контейнеры **и тестовую базу**:

```powershell
docker compose --profile web down -v
```

Команду с `-v` используйте только если хотите стереть все локальные тестовые данные.

## Что пока не делать

- Не покупать домен и VPS на этом этапе.
- Не подключать реальные SMS, почту, платежи и push.
- Не публиковать APK как production: они unsigned/debug.
- Не использовать бесплатный публичный хостинг для настоящих медицинских данных.
- Не добавлять реальные данные пациентов. Публичный демо-сервер, если он понадобится, должен содержать только синтетические данные.

## Что потребуется от владельца позже

1. Решить, где юридически будут обрабатываться данные (для целевого запуска в РФ нужны российская локализация и правовая проверка; текущий бесплатный локальный стенд не решает это).
2. Если понадобится публичный тест: выбрать регион и согласовать, что туда загружаются только вымышленные данные.
3. Для настоящего релиза отдельно: домен, TLS, резервное копирование, подпись Android/iOS/Windows, SMS-провайдер и юридические документы/проверка.
