# MedChat v2.0

**Платформа для безопасной связи врача и пациента с системой микроплатежей**

## 📋 Описание

MedChat v2.0 - это современная платформа для общения между врачами и пациентами, соответствующая всем требованиям законодательства Российской Федерации (152-ФЗ "О персональных данных", 323-ФЗ "Об основах охраны здоровья граждан").

## ✨ Ключевые возможности

### Для пациентов (мобильное приложение)
- 📱 Подключение к врачу через QR-код или ссылку
- 💬 Безопасный чат с end-to-end шифрованием
- 📎 Загрузка файлов для врача
- 🔍 Поиск по чатам
- 📊 Просмотр информации о клинике и враче
- ⚠️ Уведомление об автоудалении файлов врача через 3 дня

### Для врачей (мобильное + web)
- 💻 Доступ с любого устройства (мобильное + PC)
- 🏥 Привязка к клинике через уникальный код
- 👥 Управление пациентами
- 📁 Загрузка и просмотр файлов пациентов
- 💰 Система микроплатежей
- ⏰ Настройка удобного времени для ответов
- 🔔 Настройка уведомлений
- 📤 Экспорт/импорт данных локально

### Для клиник
- 🏢 Управление врачами
- ✅ Подтверждение регистрации врачей
- 💳 Получение части дохода от микроплатежей
- 📈 Статистика и аналитика

### Система микроплатежей
- 🆓 Бесплатные сообщения в течение 30 дней после приема
- 💰 Платные сообщения после 30 дней
- 💵 Разделение дохода: 80% врачу, 20% клинике
- 🏦 Интеграция с российскими платежными системами (YooMoney, Tinkoff)

## 🛡️ Безопасность и соответствие

- ✅ **End-to-End шифрование**: X25519 (ECDH) + XChaCha20-Poly1305
- ✅ **152-ФЗ**: Полное соответствие закону о персональных данных
- ✅ **323-ФЗ**: Соответствие закону об охране здоровья
- ✅ **ГОСТ Р 52636-2006**: Защита информации
- ✅ **ГОСТ Р ISO/IEC 27001-2006**: Системы менеджмента информационной безопасности
- ✅ **Локальное хранение**: Все данные хранятся на устройствах пользователей
- ✅ **Автоудаление**: Файлы врача удаляются через 3 дня

## 🚀 Быстрый старт

### Предварительные требования

- Node.js 18+
- Docker + Docker Compose
- PostgreSQL 14+
- Redis 7+
- MinIO (или AWS S3)

### Установка

```bash
# Клонировать репозиторий
git clone <repository-url>
cd medchat-v2

# Установить зависимости
npm run setup

# Запустить через Docker (рекомендуется)
npm run docker:up

# Или запустить вручную
npm run dev
```

### Развертывание в production

```bash
# Собрать все части
npm run build

# Запустить production сервер
cd server
npm start
```
