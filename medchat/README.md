# MedChat - Приложение для связи врача и пациента

## 📋 Описание

**MedChat** - это безопасное приложение для обмена сообщениями между врачом и пациентом, соответствующее законодательству Российской Федерации (152-ФЗ "О персональных данных").

## ✨ Ключевые особенности

### 🔒 Безопасность и конфиденциальность
- ✅ **End-to-End шифрование** - Все сообщения шифруются с использованием X25519 (ECDH) для обмена ключами и XChaCha20-Poly1305 для шифрования
- ✅ **Нет центральной базы данных** - Вся история чатов хранится только на устройствах врача и пациента
- ✅ **Локальное хранение** - Данные хранятся в зашифрованной SQLite базе на устройстве
- ✅ **Соответствие 152-ФЗ** - Полное соблюдение российского законодательства о защите персональных данных

### 🏥 Функционал для врача
- ✅ Генерация QR-кода и уникальной ссылки для подключения пациентов
- ✅ Просмотр списка пациентов
- ✅ Чат с пациентами
- ✅ Загрузка файлов к карточкам пациентов (видно только врачу)
- ✅ Настройка уведомлений
- ✅ Доступ с любого устройства

### 👥 Функционал для пациента
- ✅ Подключение к врачу через QR-код или ссылку
- ✅ Ввод уникального логина (для идентификации врачом)
- ✅ Чат с врачом
- ✅ Просмотр истории сообщений
- ✅ Нет регистрации в центральной базе

### 📱 Платформы
- ✅ **Android** - React Native
- ✅ **iOS** - React Native
- ✅ **Только мобильные устройства**

## 🚀 Быстрый старт

### 📥 Установка

#### 1. Клонируйте репозиторий

```bash
git clone https://github.com/volyyyk/chat.git
cd medchat
```

#### 2. Установите зависимости

**Сервер:**
```bash
cd server
npm install
```

**Мобильное приложение:**
```bash
cd mobile
npm install
```

### 🏃 Запуск

#### Сервер

```bash
cd server
npm start
```

Сервер будет запущен на `ws://localhost:3000`

Для производственной среды:
```bash
NODE_ENV=production npm start
```

#### Мобильное приложение

**Android:**
```bash
cd mobile
npx react-native run-android
```

**iOS:**
```bash
cd mobile
npx react-native run-ios
```

## 🔐 Протокол безопасности

### 1. Установление соединения

1. Врач генерирует пару ключей X25519 (приватный + публичный)
2. Врач подключается к серверу и получает doctorId
3. Врач генерирует QR-код с doctorId и публичным ключом
4. Пациент сканирует QR-код
5. Пациент генерирует пару ключей X25519
6. Пациент подключается к серверу, отправляет doctorId и свой публичный ключ
7. Сервер маршрутизирует публичный ключ пациента врачу
8. Врач и пациент вычисляют общий секретный ключ (ECDH)
9. Устанавливается зашифрованный канал связи

### 2. Шифрование сообщений

- **Алгоритм:** XChaCha20-Poly1305
- **Обмен ключами:** X25519 (ECDH)
- **Хэширование:** SHA-256
- **Nonce:** 24 байта (уникальный для каждого сообщения)

### 3. Хранение данных

- **Локальная база:** SQLite с шифрованием (SQLCipher)
- **Ключи:** Хранятся в ключевом хранилище устройства (Keychain на iOS, Keystore на Android)
- **Резервное копирование:** Локальное на устройстве

## 📊 Потоки данных

### Регистрация врача

1. Врач открывает приложение
2. Приложение генерирует doctorId (UUID)
3. Приложение генерирует пару ключей X25519
4. Приложение подключается к серверу
5. Сервер подтверждает подключение
6. Приложение генерирует QR-код

### Подключение пациента

1. Пациент сканирует QR-код
2. Приложение извлекает doctorId
3. Пациент вводит уникальный логин
4. Приложение генерирует пару ключей X25519
5. Приложение подключается к серверу
6. Приложение отправляет doctorId и публичный ключ
7. Сервер маршрутизирует информацию врачу
8. Устанавливается зашифрованный канал

### Отправка сообщения

1. Пользователь пишет сообщение
2. Приложение шифрует сообщение общим ключом
3. Приложение отправляет зашифрованное сообщение на сервер
4. Сервер маршрутизирует сообщение получателю
5. Получатель расшифровывает сообщение
6. Приложение сохраняет сообщение локально

## 🎯 Соответствие 152-ФЗ

MedChat полностью соответствует требованиям Федерального закона от 27.07.2006 № 152-ФЗ:

- ✅ **Минимизация данных:** Обрабатываются только необходимые данные (уникальные идентификаторы)
- ✅ **Локальное хранение:** Нет центральной базы данных
- ✅ **Согласие:** Явное согласие пациента на обработку данных
- ✅ **Конфиденциальность:** End-to-end шифрование
- ✅ **Врачебная тайна:** Защита медицинской информации (ст. 13 323-ФЗ)
- ✅ **Уровень защищенности:** УЗ-2 (в соответствии с Приказом Роскомнадзора № 28)

Подробнее: [LEGAL.md](docs/LEGAL.md)

## 🔧 Технические детали

### Сервер

- **Язык:** Node.js 18+
- **WebSocket:** ws library
- **TLS:** HTTPS/WSS
- **Логирование:** Winston
- **Ограничение частоты:** Token bucket algorithm

### Мобильное приложение

- **Фреймворк:** React Native 0.72+
- **Навигация:** @react-navigation/native
- **Хранение:** SQLite + AsyncStorage
- **Шифрование:** tweetnacl + expo-crypto
- **QR-коды:** react-native-qrcode-svg
- **Файлы:** expo-file-system, expo-document-picker

### Безопасность

- **Транспорт:** TLS 1.2+
- **Шифрование:** X25519 + XChaCha20-Poly1305
- **Аутентификация:** UUID + обмен публичными ключами
- **Защита от атак:** Replay protection, rate limiting
