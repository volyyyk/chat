# Соответствие законодательству Российской Федерации

## Введение

MedChat разработано с учетом требований:
- **152-ФЗ "О персональных данных"**
- **323-ФЗ "Об основах охраны здоровья граждан"**
- **Приказ Роскомнадзора № 28 от 18.02.2021**

## Основные принципы

### 1. Минимизация персональных данных

**Обрабатывается:**
- Уникальные идентификаторы врачей (doctorId - UUID)
- Уникальные логины пациентов (patientId) - только для идентификации врачом
- Сообщения между врачом и пациентом
- Файлы врача к карточкам пациентов

**НЕ обрабатывается:**
- ФИО пациентов
- Паспортные данные
- Адреса проживания
- Номера телефонов
- Электронные адреса
- Даты рождения

### 2. Локальное хранение

- Вся история чатов хранится только на устройствах участников
- Сервер не хранит персональные данные
- Сервер не имеет доступа к содержимому сообщений (end-to-end шифрование)

### 3. Согласие на обработку

- **Для врача:** Согласие при первом запуске
- **Для пациента:** Согласие при первом подключении
- Согласие включает: цели обработки, состав данных, сроки, порядок отзыва

### 4. Врачебная тайна (ст. 13 323-ФЗ)

- End-to-end шифрование всех сообщений
- Доступ только врачу и пациенту
- Нет центральной базы для аудита

## Реализация требований 152-ФЗ

### Статья 5. Принципы обработки
1. **Законность** - На основании согласия пациента
2. **Целесообразность** - Только для оказания медицинской помощи
3. **Минимизация** - Только необходимые данные
4. **Конфиденциальность** - End-to-end шифрование

### Статья 9. Согласие субъекта
- Явное согласие пациента при подключении
- Согласие хранится локально на устройстве

### Статья 10. Специальные категории
- Медицинские данные обрабатываются с явного согласия
- Только для оказания медицинской помощи

### Статья 19. Хранение
- Данные хранятся локально
- Пациент может удалить свою историю
- Врач может удалить карточку пациента

### Уровень защищенности: УЗ-2

**Организационные меры:**
- Врач как оператор несет ответственность
- Политика обработки персональных данных

**Технические меры:**
- Идентификация и аутентификация (UUID)
- Управление доступом (только врач и пациент)
- Защита от несанкционированного доступа (E2E шифрование)
- Контроль целостности (цифровые подписи опционально)
- Резервное копирование (локально)
- Удаление данных (возможность удаления)

## Права пациента

✅ **Право на доступ** - Пациент видит свою историю чата
✅ **Право на уточнение** - Пациент может запросить уточнение данных
✅ **Право на блокирование** - Пациент может заблокировать доступ
✅ **Право на уничтожение** - Пациент может удалить свою историю
✅ **Право на отзыв согласия** - Удаление приложения или истории

## Обязанности врача

1. Информировать пациента о обработке данных
2. Получать явное согласие
3. Обеспечивать безопасность (использовать MedChat с шифрованием)
4. Отвечать на запросы пациентов
5. Соблюдать конфиденциальность

## Заключение

MedChat обеспечивает:
- ✅ Минимизацию обрабатываемых данных
- ✅ Локальное хранение без центральной базы
- ✅ End-to-end шифрование
- ✅ Конфиденциальность медицинской информации
- ✅ Соблюдение прав пациентов

**Внимание:** Врач как оператор несет ответственность за соблюдение законодательства. MedChat предоставляет технические средства, но не освобождает врача от обязанностей оператора.
